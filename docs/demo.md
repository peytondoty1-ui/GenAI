# Recorded prototype demo

[Watch the real 2 minute 41 second MP4](https://drive.google.com/file/d/1_aQ7fVNYklS2G46TxJyBncQ-dpkYaXPi/view?usp=drivesdk).

This is an actual screen recording of the published LedgerProof prototype in an isolated Chrome browser. It shows the ink and emerald brand, a complete example, missing facts and prepared continuation, source inspection, working-note/rejection controls, conflict handling, and unresolved review requirements.

Narration uses the built-in macOS Samantha speech-synthesis voice. It is identified in the opening narration and the AI-use disclosure and does not imitate Peyton. The product's simulated drafting is a separate disclosure.

The audio and video were decoded and checked, the ending leaves room for the narration to finish, and sample frames were visually inspected. Video: H.264, 1280 by 900, 25 frames/second. Audio: AAC, 44.1 kHz mono. File size: 4,804,331 bytes.
